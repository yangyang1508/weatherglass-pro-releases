# Weatherglass Pro

**Tiếng Việt.** Bản cài đặt Weatherglass Pro: thời tiết thật ở nơi bạn sống rơi trên màn hình Mac, đọng trên mép cửa sổ.

- Tải bản mới nhất: mục [Releases](../../releases/latest), file `.dmg`.
- Máy cần: macOS 13 trở lên, chip Apple hoặc Intel.
- Mua và kích hoạt: <https://yangopen.com/apps/weatherglass-pro/>

Repo này chỉ chứa file cài đặt, không chứa mã nguồn. File đã được ký và công chứng (notarized) bởi Apple.
